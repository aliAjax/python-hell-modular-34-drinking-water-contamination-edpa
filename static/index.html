市政饮用水污染响应

使用 JSON API 创建污染事件、登记水源或管网记录，并完成复检、通知、冲洗、消毒和恢复。

冲洗与消毒共用移动消毒机组：开批占用机组与支路，回执带回实际加药量；污染来源更新时整批失效、下游已恢复区域退回待复检；先到者领批、后到者拿排队号，回执失败按序重试且不重复加药；监管可跨支路放行，现场越界返回 403。
